# Flash Breaker: 8-Bit

Welcome to **Flash Breaker: 8-Bit**, a retro-inspired brick breaker experience featuring dynamic chip-tune audio and classic pixel aesthetics.

## How to Play

To launch the game, simply double-click the `index.html` file. The game will run directly in your default web browser. No installation or external dependencies are required.
